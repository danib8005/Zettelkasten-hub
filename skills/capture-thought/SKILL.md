# Capture a thought

Follow `AGENTS.md`. Tool-neutral: use whatever file access you have; without it, show the note in the chat.

## Procedure
1. **Keep the raw wording.** Put the owner's words as they came into the raw-idea section, with the date. Only correct typos; do not polish.
2. **Check for neighbours.** Use [`find-existing`](../find-existing/SKILL.md) on the key terms. If a concept with the same idea exists, name it as a possible link instead of restating it.
3. **Fill the template.** Use `templates/thought.md`: raw idea, core idea in one or two sentences, optionally why it is not trivial, possible links with a reason each.
4. **Save directly.** No draft needed for a thought. File name: `10_Concepts/<short-title>.md`. Review status: 💭 idea, signed with your tag.
5. **Report.** What was saved; suggest Connect if the thought could become a concept or join a synthesis.

## Final check
- The owner's wording is kept; your additions are marked `📝 Agent:`.
- Nothing presented as a finding that is only an idea.
