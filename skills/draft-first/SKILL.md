# Draft first, save after confirmation

Follow `AGENTS.md`. Tool-neutral: without file access, the confirmed draft is the result; the person saves it.

## Procedure
1. **Show the draft in the chat.** The full note (filled template, core statement first), then outside the note:
   - **Context:** what it relates to and why now;
   - **Links:** each target with a reason (open targets are fine);
   - **Questions to think about:** one or two. They do not go into the note.
2. **Wait for confirmation.** Apply the person's corrections and show the changed parts again if they are substantial.
3. **Save.** File name rule from `AGENTS.md` (source notes `lastname-year-shorttitle.md`). Set `type:`; set `visibility:` only if the person says so (missing means private). Add the review status block with the date and your agent tag.
4. **Changes to existing notes.** Announce what and why before you change them; small corrections need no draft, anything that changes the meaning does.

## Final check
- Nothing saved without confirmation; nothing deleted.
- The thinking questions stayed out of the note.
- Review status block present and signed.
