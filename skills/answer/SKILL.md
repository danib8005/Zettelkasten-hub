# Answer from the notes

Answer a question from the bundle, not from general knowledge. The answer is the proof that the notes work.
Follow the rules in `AGENTS.md`. Tool-neutral: use whatever search and file access you have; with only a pack file, use the notes in it.

## Procedure
1. **Clarify the question.** What kind of answer is needed (short and practical, structured for teaching, citable for academic use)? Ask only if the choice changes the answer a lot; otherwise pick the shortest fitting form and say which.
2. **Search the bundle.** Search for the key terms and their related terms and `aliases:` in `10_Concepts/`, `40_Sources/`, `70_Tools/`. Check `perspective.md` for the owner's terms and anchors.
3. **Read and rate.** For each hit read the relevant part and rate it: main source, supplement or marginal. Note the review status (⚠️ outdated counts as a caveat). Priority: concept notes (already synthesised) → source notes → tools → thoughts. Keep this rating; you need it if asked «Warum diese Zettel?».
4. **Write the answer.**
   - Core statement first, in one or two sentences.
   - Then the points, each with its origin: the note path, e.g. `(/40_Sources/albers-2024-optimierungsluege.md)`.
   - Distinguish: what a source says, what the owner noted (`📝 Deine Notiz`), your interpretation (label it as hypothesis).
   - Short quotes only in the original language and with source; otherwise paraphrase. Never invent a quote, a location or a source.
   - End with **Gaps**: what the notes do not cover, what is open, where sources disagree.
5. **Be honest about limits.** If the notes are thin: say what is covered and what is missing. If you add general knowledge, label it «not from the notes» and never present it as a finding. If the answer is not in the notes, say so plainly; that is a valid answer.
6. **Pointers.** List notes the person may want to read and open questions from `50_Open-Questions/` that touch the topic.

## On request: explain the selection
Only when asked («Warum diese Zettel?»), answer in a few sentences: which notes carried the answer and which only supplemented it; which kinds of notes were checked and which were missing or did not fit; what was left out on purpose. Do not volunteer it.

## Final check
- Every statement has an origin or is labelled hypothesis / not from the notes.
- Core statement first; answer in the language of the question.
- Gaps are listed; nothing is invented.
