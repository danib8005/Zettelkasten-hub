# Write a concept or framework

Follow `AGENTS.md` and your agent file. Tool-neutral.

## Procedure
1. **Pick the type.** One idea, explained in 1–2 pages → concept (`templates/concept.md`). A reusable way of thinking with components and a guiding question → framework (`templates/framework.md`).
2. **Check what exists** with [`find-existing`](../find-existing/SKILL.md). If the idea exists, extend that note or add an alias; do not create a second definition.
3. **Gather the material** from source notes and thoughts in the bundle. Draw from the material before attaching it to the owner's favourite topics.
4. **Write.**
   - Concept: the standard definition in the core idea, in one to three sentences, with its source. Other notes link here instead of redefining. Set `Level:` / `Ebene:` (micro, meso, macro; ranges allowed) if it helps.
   - Framework: name the guiding question; describe the components; say where it fits and where it does not.
5. **Links.** Each with a reason, ideally both ways; only towards the more general.
6. **Hand over to [`draft-first`](../draft-first/SKILL.md).**

## Final check
- One definition, with origin; no redefinition of a concept that exists elsewhere.
- Framework: guiding question and limits stated.
- Links bundle-relative, each with a reason.
