# Write a tool note

Follow `AGENTS.md` and your agent file. Tool-neutral.

## Procedure
1. **Check what exists** with [`find-existing`](../find-existing/SKILL.md) in `70_Tools/` and the concepts it builds on.
2. **Fill `templates/tool.md`.** Purpose in one sentence; kind, effort, prerequisite.
3. **Say when it fits.** A concrete trigger ("if X, use this"), when not to use it, and what makes it work.
4. **Write the tool itself** so that it can be used without reading anything else: checklist, questions, matrix or steps.
5. **Background and links.** Where it comes from; link the concepts and sources it rests on, each with a reason. Do not invent an origin; an own invention is marked as such.
6. **Hand over to [`draft-first`](../draft-first/SKILL.md).**

## Final check
- Usable on its own; trigger and limits stated.
- Origin named or marked as own invention.
