# Konfliktnotiz — Widersprüche entscheiden, ohne den Strang zu beenden

## Kurzüberblick
| | |
|--|--|
| **Art** | Schreibformat (6 Zeilen) |
| **Aufwand** | 15–30 Min |
| **Voraussetzung** | Zwei bestehende Zettel, die sich in einer *Aussage* widersprechen (nicht bloss thematisch verwandt sind) |

## Zweck
Der Ort, an dem Wertung strukturell erzwungen wird, statt nur möglich zu sein.

## Einsatz
**Eignet sich für:** Zettelkasten-Pflege, Synthese-Vorbereitung, Selbstreflexion
**Wann einsetzen:** Wenn eine Verbindung als «Kontrast» markiert ist, aber nie entschieden wurde.
**Wann nicht:** Bei blosser Themenverwandtschaft. Dafür reicht eine Verbindung mit benanntem Modus.
**Damit es klappt:** Die Gegenposition nie vollständig wegentscheiden.

## Das Tool
1. **Position A** — Zettel + Aussage
2. **Position B** — Zettel + Aussage
3. **Worin genau** besteht der Widerspruch? (Aussage, nicht Thema)
4. **Was hängt** von der Entscheidung ab?
5. **Eigene Position** und Begründung
6. **Was von der Gegenposition bestehen bleibt**

Zeile 6 ist die entscheidende: Eine Konfliktnotiz, die eine Seite vollständig wegentscheidet, ist nicht mehr anschlussfähig. Sie beendet den Strang, statt ihn weiterzuführen.

*Format im Gespräch entwickelt (DB+Claude, 2026-07-26).*

## Hintergrund
Entstanden aus der Beobachtung, dass ein Zettelkasten fast nur bestätigende Verbindungen kennt («Resonanz mit»). Eine Liste von Beziehungen inventarisiert nur. Wirksamer ist die Form «Zettel X und Y widersprechen sich in Z, meine Position: …». Das folgt einer Lesart von Luhmanns Kartei: Sie funktionierte, weil die Zettel miteinander «sprachen», nicht weil sie inventarisiert waren.
